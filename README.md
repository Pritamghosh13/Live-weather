# 🌦️ Weather App

A simple and responsive weather web application that provides real-time weather updates using an external API.

🌐 **Live Website:** https://live-weather78.netlify.app/

---

## 👨‍💻 Author

**Pritam Ghosh**

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡️ Real-time temperature display  
- ☁️ Weather conditions (Clouds, Rain, Clear, etc.)  
- 💨 Wind speed and humidity  
- 📱 Responsive UI for all devices  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  
- Weather API (OpenWeather / similar)
